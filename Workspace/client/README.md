This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

The application uses locally available system font stacks and does not load Google Fonts or another external font service.

## Production hosting

The production application is hosted on Hetzner Webhosting and is available at
[luxor-drive.de](https://luxor-drive.de/). Contact-form messages are delivered through
the configured Hetzner SMTP mailbox using Nodemailer; credentials remain in environment variables.
